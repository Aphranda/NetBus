# A1 检波板 CAN 指令表 (V3.x)

## 通信协议约定

| 项目 | 说明 |
|------|------|
| 总线类型 | Classic CAN / CAN FD（OTA帧支持 8~64 字节） |
| 默认帧长度 | 8 字节（OTA 数据帧除外） |
| 请求帧 Byte0 | 目标 Node ID（0xFF = 广播） |
| 响应帧 ID | nodeId（目标节点回显自身 ID） |
| 响应帧 Byte0 | 命令字回显（低字节，如 0x114 → 0x14） |
| 响应帧 Byte1 | 结果码（0x00=成功，0x01=失败，其余为扩展状态） |

---

## 一、系统指令 (0x101–0x108)

### 0x101 — 读取 SN

| 方向 | 字节 | 说明 |
|------|------|------|
| 请求 | D[0] | Node ID |
| 响应 | D[0] | 0x01 |
| 响应 | D[1] | 0x00 |
| 响应 | D[2] | SN 字符串长度 (0–61, 0 表示未写入或损坏) |
| 响应 | D[3+] | SN 字符串内容（可打印 ASCII） |

---

### 0x102 — 写 Node ID

| 方向 | 字节 | 说明 |
|------|------|------|
| 请求 | D[0] | Node ID |
| 请求 | D[1] | 复位标志：1=复位, 0=不复位 |
| 请求 | D[2] | 新 Node ID（1–40） |
| 响应 | D[0] | 0x02 |
| 响应 | D[1] | 结果：0=ok, 1=fail, 2=参数错误 |
| 响应 | D[2] | 当前 Node ID |

> 复位操作：擦除 Node ID 所在 Flash 页，固件启动后恢复默认值 1

---

### 0x103 — 读取版本

| 方向 | 字节 | 说明 |
|------|------|------|
| 请求 | D[0] | Node ID |
| 响应 | D[0] | 0x03 |
| 响应 | D[1] | 0x00 |
| 响应 | D[2–4] | 版本号 major.minor.patch |

---

### 0x104 — 复位 MCU

| 方向 | 字节 | 说明 |
|------|------|------|
| 请求 | D[0] | Node ID |
| 响应 | D[0] | 0x04 |
| 响应 | D[1] | 0x00（应答后执行复位） |

---

### 0x105 — LED 控制

| 方向 | 字节 | 说明 |
|------|------|------|
| 请求 | D[0] | Node ID |
| 请求 | D[1] | 0=停止闪烁, 1=开始闪烁 |
| 请求 | D[2–3] | 闪烁周期 (ms), 0~1000ms |
| 响应 | D[0] | 0x05 |
| 响应 | D[1] | 0x00 |

---

### 0x106 — 写 SN

| 方向 | 字节 | 说明 |
|------|------|------|
| 请求 | D[0] | Node ID（不支持广播） |
| 请求 | D[1] | SN 字符串长度 (1–61) |
| 请求 | D[2+] | SN 字符串内容 |
| 响应 | D[0] | 0x06 |
| 响应 | D[1] | 结果码（见下方状态表） |
| 响应 | D[2] | 写入的 SN 长度（失败时为 0） |
| 响应 | D[3+] | 写入的 SN 内容（失败时为空） |

**响应 D[1] 状态码：**

| 值 | 含义 |
|----|------|
| 0x00 | 成功 |
| 0x01 | 写 Flash 失败或回读校验不一致 |
| 0x02 | 参数错误 |
| 0x04 | 当前在 OTA 状态，被拒绝 |
| 0x05 | 当前在校准状态，被拒绝 |
| 0x06 | 当前未进入 SN 写状态 |

> **推荐流程：** `0x107("gts")` → `0x106(写SN)` → `0x108("exit")`

---

### 0x107 — 进入 SN 写状态

| 方向 | 字节 | 说明 |
|------|------|------|
| 请求 | D[0] | Node ID（不支持广播） |
| 请求 | D[1–3] | ASCII "gts" |
| 响应 | D[0] | 0x07 |
| 响应 | D[1] | 结果码 |

**响应 D[1] 状态码：**

| 值 | 含义 |
|----|------|
| 0x00 | 进入成功 |
| 0x02 | 参数/长度错误 |
| 0x04 | OTA 状态拒绝 |
| 0x05 | 校准状态拒绝 |
| 0x07 | 已在 SN 写状态 |

---

### 0x108 — 退出 SN 写状态

| 方向 | 字节 | 说明 |
|------|------|------|
| 请求 | D[0] | Node ID（不支持广播） |
| 请求 | D[1–4] | ASCII "exit" |
| 响应 | D[0] | 0x08 |
| 响应 | D[1] | 结果码 |

**响应 D[1] 状态码：**

| 值 | 含义 |
|----|------|
| 0x00 | 退出成功，切回空闲态 |
| 0x02 | 参数/长度错误 |
| 0x04 | OTA 状态拒绝 |
| 0x06 | 当前未在 SN 写状态 |

### 0x113 — 衰减器手动设置

| 方向 | 字节 | 说明 |
|------|------|------|
| 请求 | D[0] | Node ID |
| 请求 | D[1] | ATT1 (0–15) |
| 请求 | D[2] | ATT2 (0–15) |
| 请求 | D[3] | ATT3 (0–15) |
| 请求 | D[4] | ATT4 (0/7/8/15) |

### 0x114 — VCO 频率设置

| 方向 | 字节 | 说明 |
|------|------|------|
| 请求 | D[0] | Node ID (0xFF=广播) |
| 请求 | D[1] | 通道：0=关, 1=V, 2=H |
| 请求 | D[2–5] | 基准频率 (KHz, 32bit LE) |
| 请求 | D[6] | LMX 输出功率 (0–63, 原始寄存器值) |
| 请求 | D[7] | 0x00 |
| 响应 | D[0] | 0x14 |
| 响应 | D[1] | 0=成功, 1=失败 |
| 响应 | D[2] | 通道回显 (0/1/2) |
| 响应 | D[3–6] | 实际频率 (KHz, 32bit LE) |
| 响应 | D[7] | LMX 功率回显 (0–63) |

---

### 0x115 — 波段选择

| 方向 | 字节 | 说明 |
|------|------|------|
| 请求 | D[0] | Node ID (0xFF=广播) |
| 请求 | D[1] | 波段 (MHz) |
| 请求 | D[2] | 模式：0=单频点, 非0=扫频 |
| 请求 | D[3–7] | 40bit 位掩码 (LE: D[3]=bit0-7) |
| 响应 | D[0] | 0x15 |
| 响应 | D[1] | 0x00 |
| 响应 | D[2] | 模式回显 (0/1) |
| 响应 | D[3] | 当前节点 V 通道选中状态 (0/1) |
| 响应 | D[4] | 当前节点 H 通道选中状态 (0/1) |

**40bit 位掩码编码规则：**

| bit | 含义 | bit | 含义 |
|-----|------|-----|------|
| 0 | 1H | 1 | 1V |
| 2 | 2H | 3 | 2V |
| ... | ... | 38 | 20H |
| 39 | 20V |

> 同一点 H/V 同时为 1 时，默认保留 H 而舍弃 V

## 三、功率指令 (0x11B–0x11C)

### 0x11B — 检波功率查询 (12B CAN FD)

| 方向 | 字节 | 说明 |
|------|------|------|
| 请求 | D[0] | Node ID |
| 请求 | D[1–3] | 频率 (KHz, 24bit LE) |
| 请求 | D[4] | 保持时间 (ms) |
| 请求 | D[5] | 模式：0=定时, 1=触发, 2=脉冲 |
| 请求 | D[6–7] | 阈值 (16bit) |
| 请求 | D[8–9] | 门限时间 (ms, 16bit) |
| 请求 | D[10] | Bit0: 是否补偿线损校准数据 (0/1) |
| 请求 | D[11] | 保留 |
| 响应 | D[0] | 0x1B |
| 响应 | D[1] | 结果码 |
| 响应 | D[2–3] | H 通道功率 (dBm×100, int16) |
| 响应 | D[4–5] | V 通道功率 (dBm×100, int16) |
| 响应 | D[6] | 模式回显 |
| 响应 | D[7] | 状态 (同 0x110) |

**响应 D[1] 状态码：**

| 值 | 含义 |
|----|------|
| 0x00 | 成功 |
| 0x01 | 操作失败 / OTA/校准/SN写状态拒绝 |
| 0x02 | 校准数据非法/未写入/参数超限 |

> 内部执行流程：执行一次 0x110 同等测量 → 获取 H/V ADC 平均值 → 查校准表按频率插值 → 转换为功率。补偿模式下同时补偿线损。

---

### 0x11C — 发射功率设置 (12B CAN FD, 响应 16B)

| 方向 | 字节 | 说明 |
|------|------|------|
| 请求 | D[0] | Node ID |
| 请求 | D[1] | 通道：0=关, 1=V, 2=H |
| 请求 | D[2–5] | 目标频率 (KHz, 32bit LE) |
| 请求 | D[6–7] | 目标功率 (dBm×100, int16) |
| 请求 | D[8] | GPS 标志：0=无GPS, ≠0=有GPS |
| 请求 | D[9] | Bit0: 是否补偿线损校准数据 |
| 请求 | D[10–11] | 保留 |
| 响应 | D[0] | 0x1C |
| 响应 | D[1] | 0x00=成功, 0x01=LMX失败, 0x02=参数非法 |
| 响应 | D[2] | 通道回显 (0/1/2) |
| 响应 | D[3–6] | 实际设置频率 (KHz, 32bit LE) |
| 响应 | D[7] | ATT1 |
| 响应 | D[8] | ATT2 |
| 响应 | D[9] | ATT3 |
| 响应 | D[10] | ATT4 |
| 响应 | D[11] | ATT5 |
| 响应 | D[12] | ATT6 |
| 响应 | D[13] | ATT7 |
| 响应 | D[14–15] | 预测功率 (dBm×100, int16) |

> 闭环逻辑：设置频率 → LMX 输出（功率固定为最小） → 查校准表获取参考值和补偿 → 计算最接近目标功率的衰减值 → 下发 ATT。GPS=1 时 ATT6 固定为 1（额外 30dB 增益），GPS=0 时 ATT6=0。

## 六、OTA 指令 (0x1A0–0x1A3, 0x300–0x3FF)

### OTA 流程

```
0x1A0 (准备) → 0x1A1 (开始页) → 0x300+ (数据块) × N → 0x1A3 (完成/复位)
```

---

### 0x1A0 — OTA 准备

| 方向 | 字节 | 说明 |
|------|------|------|
| 请求 | D[0] | Node ID |
| 请求 | D[1–3] | 目标版本号 major.minor.patch |
| 响应 | D[0] | 0xA0 |
| 响应 | D[1] | 状态码 |

| 值 | 含义 |
|----|------|
| 0x00 | 可进入 OTA（已切换到 OTA 状态） |
| 0x03 | 版本一致，无需更新 |
| 0x04 | 已在 OTA 状态 |
| 0x05 | 校准状态拒绝 |
| 0x07 | SN 写状态拒绝 |

---

### 0x1A1 — OTA 开始 (页写入准备)

| 方向 | 字节 | 说明 |
|------|------|------|
| 请求 | D[0] | Node ID |
| 请求 | D[1] | 保留 |
| 请求 | D[2–3] | 页号 (16bit LE) |
| 响应 | D[0] | 0xA1 |
| 响应 | D[1] | 0x00=成功, 0x01=失败 |

---

### 0x300–0x3FF — OTA 数据块

| 方向 | 说明 |
|------|------|
| 请求 ID | `0x300 + blockNum` (0x300–0x3FF) |
| 请求 Data | 固件数据 (推荐 64B CAN FD) |
| 响应 ID | `0x400 + NodeID` |
| 响应 D[0] | blockNum 回显 |
| 响应 D[1] | 0x00=成功, 0x01=失败 |

---

### 0x1A3 — OTA 完成

| 方向 | 字节 | 说明 |
|------|------|------|
| 请求 | D[0] | Node ID |
| 请求 | D[1] | 完成后是否复位：1=复位, 0=不复位 |
| 请求 | D[2–3] | CRC (16bit LE) |
| 请求 | D[4–7] | 固件总长度 (32bit LE) |
| 响应 | D[0] | 0xA3 |
| 响应 | D[1] | 0x00=成功（校验通过）, 0x01=校验失败 |

> 完成后状态切换回 IDLE；若复位标志=1 且 CRC 校验成功，自动执行系统复位加载新固件。

## 七、调试 CLI 对应表

调试控制台（UART7, 115200 8N1）输入 `detector help` 查看子命令。

| CLI 子命令 | CAN 指令 | 说明 |
|-----------|---------|------|
| `detector sn <id>` | 0x101 | 读取序列号 |
| `detector nodeid <id> <new>` | 0x102 | 写 Node ID |
| `detector version <id>` | 0x103 | 读取固件版本 |
| `detector reset <id>` | 0x104 | 复位 MCU |
| `detector led <id> <0/1> [period]` | 0x105 | LED 控制 |
